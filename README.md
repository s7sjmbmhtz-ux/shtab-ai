# ШТАБ AI — Telegram AI Assistant

## 🚀 О проекте

ШТАБ AI — Telegram-бот с 5 AI-инструментами для бизнеса.

## 🛠 Инструменты

- 📞 Скрипт продаж
- 📝 Продающий пост
- 🖼 Генерация изображений
- 🤖 AI Ассистент
- 🛒 Маркетплейс

## 🏗️ Архитектура

- Python 3.12+
- aiogram 3.x
- SQLite
- Pipeline Architecture
- Tool Registry
- Provider abstraction

```bash
git clone https://github.com/your-repo/shtab-ai.git

# Заполните .env своими данными
