ПАКЕТ 03 — ИСТОРИЯ И АДМИНКА ТОКЕНОВ

1. Добавьте token_admin_handlers.py в корень проекта.
2. Полностью замените app.py файлом из архива.
3. Остальные файлы не удаляйте.

Команды пользователя:
/history — последние операции с токенами.

Команды администратора:
/grant TELEGRAM_ID КОЛИЧЕСТВО [причина]
/price MODEL_KEY ЦЕНА
/models

Важно: администратор определяется по ADMIN_TELEGRAM_ID в .env.
